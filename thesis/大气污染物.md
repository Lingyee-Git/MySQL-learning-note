
## 1. PCOS患者-家庭住址匹配

```sql
CREATE TABLE `PCOS患者就诊事件-住址` AS

SELECT
  `身份证号`,
  NULL AS `住院号`,
  `就诊ID号`,
  `家庭住址`,
  `就诊时间` AS `时间`,
  '门诊' AS `数据来源`
FROM `门诊信息-pcos筛选（未排除？）`

UNION ALL

SELECT
  `身份证号`,
  `住院号`,
  NULL AS `就诊ID号`,
  `家庭住址`,
  `入院时间` AS `时间`,
  '住院' AS `数据来源`
FROM `住院信息-pcos筛选`
```
